The second prerelease of Super Smash Bros.: Recompiled for Windows and Linux: a native PC port of the N64 game made by static recompilation. It is not an emulator and contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 16 MiB, SHA-1 `e2929e10fccc0aa84e5776227e798abc07cedabf`). Other regions and revisions are not supported.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- **Rumble.** Each port with a controller now holds a Rumble Pak, as a console with one in every pad does, so a gamepad rumbles when the game asks for it (it never did before). Its strength is the settings menu's General tab's.
- **A crash fixed:** How to Play, started from the Data menu and watched to its end, stopped the game as it went on to the character data screen. It now goes on to that screen and the demo battle as a console does.

**Windows:** unzip `SmashBrosRecompiled-v0.1.1-windows-x64.zip` and run `SmashBrosRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `SmashBrosRecompiled-v0.1.1-linux-x64.tar.gz` and run `SmashBrosRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**. Your saves and settings from v0.1.0 carry over: they are kept in your user profile, not beside the program.

**Not checked yet:** how the rumble feels on a real pad, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only).

The [README](https://github.com/n64hub/super-smash-bros-recomp#readme) has what works and how to build it yourself.
