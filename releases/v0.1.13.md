An update of the renderer and runtime every recomp of this project shares. Like v0.1.12 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 16 MiB, SHA-1 `e2929e10fccc0aa84e5776227e798abc07cedabf`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `SmashBrosRecompiled-v0.1.13-windows-x64.zip` and run `SmashBrosRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `SmashBrosRecompiled-v0.1.13-linux-x64.tar.gz` and run `SmashBrosRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**Fixed:**

- The frame shown is always the one the game points the screen at.
- Drawing and showing an interpolated frame no longer race each other.
- The picture's bottom row is drawn at every window size.
- A frame is no longer shown while it is still being drawn, which could leave out what the game draws last in it.

These come with N64Recomp-browser v0.205.0's renderer and runtime.

The [README](https://github.com/n64hub/super-smash-bros-recomp#readme) has what works and how to build it yourself.
