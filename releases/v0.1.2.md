The third prerelease of Super Smash Bros.: Recompiled for Windows and Linux: a native PC port of the N64 game made by static recompilation. It is not an emulator and contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 16 MiB, SHA-1 `e2929e10fccc0aa84e5776227e798abc07cedabf`). Other regions and revisions are not supported.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new:**

- **Every pad's port from the start.** With pads plugged in as the game starts, it sees each of them at once: it saw port 1's alone until it asked again, so only player 1's pad had its Rumble Pak at first.
- **The keyboard's keys on the Controls tab.** Reset to defaults gives a keyboard player the default keys again: it cleared them, leaving the player with none. (A second player sharing the keyboard still starts with none, so the two players' keys don't overlap.) And a gamepad player 1, who also plays the keyboard until another player is given it, now has the controller/keyboard switch at the bottom of their Edit page, to see and change those keys.

**Windows:** unzip `SmashBrosRecompiled-v0.1.2-windows-x64.zip` and run `SmashBrosRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `SmashBrosRecompiled-v0.1.2-linux-x64.tar.gz` and run `SmashBrosRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**. Your saves and settings from earlier releases carry over: they are kept in your user profile, not beside the program.

**Not checked yet:** how the rumble feels on a real pad, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only).

The [README](https://github.com/n64hub/super-smash-bros-recomp#readme) has what works and how to build it yourself.
