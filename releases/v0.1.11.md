Widescreen battles. Like v0.1.10 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 16 MiB, SHA-1 `e2929e10fccc0aa84e5776227e798abc07cedabf`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `SmashBrosRecompiled-v0.1.11-windows-x64.zip` and run `SmashBrosRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `SmashBrosRecompiled-v0.1.11-linux-x64.tar.gz` and run `SmashBrosRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- In a window wider than 4:3, the battle HUD (each player's damage and stocks, the timer, the Bonus Practices' targets) spreads to the window's sides, where it was held in the middle 4:3.
- In a window wider than 4:3, a fighter in the picture's sides is drawn there, where it vanished into a magnifying bubble at the middle 4:3's edge.

The [README](https://github.com/n64hub/super-smash-bros-recomp#readme) has what works and how to build it yourself.
