Smoother motion and fixes in the shared renderer, and a start on Windows PCs with little memory to spare. Like v0.1.4 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 16 MiB, SHA-1 `e2929e10fccc0aa84e5776227e798abc07cedabf`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `SmashBrosRecompiled-v0.1.5-windows-x64.zip` and run `SmashBrosRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `SmashBrosRecompiled-v0.1.5-linux-x64.tar.gz` and run `SmashBrosRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- **Smoother scrolling textures:** textures the game scrolls slowly, such as water and skies, move smoothly on every frame drawn instead of in steps.
- **Smoother motion for more shapes:** shapes the game moves itself, without giving the renderer an ID to follow them by, glide between frames instead of moving only on the game's own frames.
- **No more giant stray objects:** a rare frame where a far, small object could be drawn huge in front of everything is gone.
- **Starts on a PC with little memory to spare (Windows):** the game commits only the 512 MB of console memory it uses, so it no longer stops at start with "Failed to allocate memory!".

The [README](https://github.com/n64hub/super-smash-bros-recomp#readme) has what works and how to build it yourself.
