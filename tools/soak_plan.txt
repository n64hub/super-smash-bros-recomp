# The desktop build's soak plan, for frame_dump.mjs --soak 150: one round through the game's modes and scenes, a
# player's keys and random ones, which fails on a crash, an exit, or a picture standing still for 10 s. A round plays
# the boot and the opening to the title with Start (Enter), the main menu, VS Mode with the stick (S) and A (Space),
# and character select, then a VS battle of four computer players (Mario, Link, Pikachu, Ness) on Peach's Castle with
# items, started as character select and stage select start one, 35 s of it with random keys, its clock run out and
# its results (after Sudden Death if it ties), and Start back to character select. From there it plays Bonus 1
# Practice (Break the Targets) as Mario, 20 s of random keys, left as a player leaves it (Start, then A, B, Z and R
# held together) to its character select, and then the 1P Game's first stage (Link) as Mario, its intro and the
# battle with random keys to the end. Start and Escape are never random keys: a pause or the recomp's menu would stand
# still. Training Mode is left out: A, B, Z and R don't end it, only its pause menu does.
#
# The writes are tools/shader_survey.js's vs(), bonus() and spgame() as 32-bit words, each word's other bytes as the
# game holds them at character select. The scene is gSCManagerSceneData.scene_curr (0x800A4AD0, its high byte; 1 the
# title, 7 the main menu, 9 VS Mode, 16 VS character select, 19 Bonus 1's character select, 22 a VS battle, 24 its
# results, 52 the 1P Game, 53 a Bonus stage), the next scene loads once sSYTaskmanStatus (0x800465D0) is 1, the battle
# state's pointer is 0x800A50E8 (0x800A4D08 a VS battle's, 0x800A4B18 the 1P Game's) and its second byte the stage
# (0 Peach's Castle, 4 the 1P Game's Link stage, 17 Mario's Break the Targets), the main menu's cursor is 0x80132C88.
